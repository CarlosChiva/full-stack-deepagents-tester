# REQUIREMENTS — Chat Web App

## Descripción
Aplicación web de chat en tiempo real.

## Tecnologías requeridas
- **Frontend Framework:** React
- **Lenguaje:** TypeScript
- **Estilos:** TailwindCSS
- **Gestión de Estado:** Context API
- **Contenedores:** Docker

## Componentes principales
1. **Sidebar** — Lista de conversaciones/chatrooms, navegación entre canales.
2. **Chat Window** — Área principal de mensajes con input de texto y scroll de conversación.

## Funcionalidades
- Interfaz de chat con sidebar lateral.
- Ventana de chat principal con mensajes y entrada de texto.
- Gestión de estado global con Context API.
- Contenedor Docker para desarrollo y producción.

## Criterios de aceptación
- La app se ejecuta dentro de un contenedor Docker.
- Interfaz responsive con TailwindCSS.
- Tipado estricto con TypeScript.
- Estado centralizado con React Context.
